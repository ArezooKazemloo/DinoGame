Free Dino Sprite Pack - cartoon character art

Source: https://opengameart.org/content/free-dino-sprites
Author: pzUH
License: CC0 (public domain dedication)

This pack contains 48 separate PNG frames in five animation folders: Dead, Idle, Jump, Run, and Walk. The editor utility now prefers these cartoon frames when it creates the player animations, and falls back to the original character if the pack is missing.

To apply the cartoon character, open the game scene and run **Dino Game > Setup Animator (Run, Jump, Hit, Death)**. This imports the run, jump, and dead sequences as smooth sprites and assigns them to Player. The original dinosaur PNGs are kept as a fallback.
